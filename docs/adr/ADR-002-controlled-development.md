# ADR-002：设置、资料与受控开发链路

状态：实施；2026-11-04。

用户补充要求可直接改代码、管理多模型与资料、查看 Git 历史并提交推送。固定 Codex Runtime 在此机的 Windows 原生沙箱尚未配置，直接开放完整本机 Shell 无法证明边界。

决定保留 Codex app-server 推理和工具循环，在 `environments: []` 的 turn 中提供平台受控文件工具，支持真实文件新增/修改/删除。主进程限定会话隔离 Worktree，hash 乐观校验、防目录链接/敏感路径检查，并在写入前执行强制要求回调；不为了开发能力而开启任意 Shell。原生沙箱和实际构建测试作为后续独立模块，不删掉需求。

开发要求分为完整正文上下文和可判定 JSON 规则。机器规则在实际写入和提交 blob 上阻断；自然语言在提交前逐份确认。不能将“模型被提示遵守”当作所有规范已被程序证明。

多中转站元数据、主题、记忆和导入资料使用 SQLite v2；凭据以独立 DPAPI 文件绑定服务地址，保持 Renderer 不回显与无服务器部署。Jira 本次完成凭据配置，业务任务连接仍按正式 PRD 分阶段推进。

Git 操作为应用按钮独立发起，确认分支和文件后提交/推送，仅会话 agent 分支。暂存后对真实 Git blob 再审核，再固定 tree 生成 commit 并以旧 SHA 条件更新目标分支，防止工作树与 Git 规范化内容不一致。绝不自动提交开发主仓库、生产分支或发布。
