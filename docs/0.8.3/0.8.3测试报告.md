- `npm run build`：通过。
- 0.8.3 学习引擎、Skill 匹配、插件管理和 Runtime 专项：44/44 通过。
- SQLite 迁移专项：26/26 通过；Schema 从 13 升级到 14，迁移测试覆盖旧版本数据保留和迁移前备份。

## 已实现

- 从完成任务、当前契约和真实证据检查候选准入；失败任务只生成不可发布的问题复盘候选。
- 本地生成确定性草稿；AI 整理须用户显式选择模型、选择证据并确认发送内容及费用提示。候选编辑、校验、人工批准、拒绝和发布均受 revision CAS 保护。
- 发布前执行敏感内容扫描及现有 Plugin Validator；发布生成受管 Plugin，并记录候选、来源任务、发布时间、适用范围、前序版本和内容 Hash；默认禁用或限项目范围。
- 使用事件可查看推荐、选择、加载、加载失败、资源读取和跳过记录；支持 helpful / not_helpful / incorrect 人工反馈。

## 未完成验收项

- 文档要求的 `used`、`task_completed`、`verified_passed`、`accepted` 任务结果关联与聚合效果趋势尚未接通；当前事件日志不能据此宣称 Skill 提升了任务成功率。
- 版本链和范围设置已展示；独立的弃用状态及一键回滚流程尚未实现。既有会话仍按其原 Snapshot 运行。
- 未执行真实外部模型计费调用、目标 Runtime 的桌面端端到端验收或安装后 Windows 冒烟测试；单元/合成测试不代表这些验收已完成。

上述未完成项和两项回归失败需单独补齐/排查，故本报告不将 0.8.3 标记为全部验收通过。
