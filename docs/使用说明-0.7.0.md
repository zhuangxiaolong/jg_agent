# 精工 Agent 0.7.0 使用说明

## 已接入能力

- 版本号升级为 `0.7.0`，构建与发布工作流增加质量门禁。
- 验证服务新增 `.NET` 解决方案测试配置 `dotnet-tests`，使用 TRX 机器可读报告并纳入证据链。
- 验证包新增确定性 TRX 解析器，空报告、未知状态、损坏 XML 均保持 fail closed。
- Runtime 能力视图区分静态接入声明与最近一次实测状态；未执行能力不会伪装成通过。
- 新增操作手册领域包，支持按 MES5/MES6/WMS 系统隔离检索、来源定位、待确认标记和 Markdown 导出。

## 验证结果

已执行 `npm run build`，通过。

已补充 TRX 解析与操作手册领域测试。完整 `npm test` 的基线结果仍有 11 项既有失败，集中在任务治理、自动子 Agent 可用性、Git 权限和 session memory；因此当前版本尚未满足 0.7.0 发布条件。真实模型 Runtime API、Windows 桌面交互、.NET 解决方案实测和操作手册 DOCX/PDF 导出尚未执行。

## 使用限制

操作手册当前为领域层能力，尚未接入本地数据库、IPC 设置页和 DOCX/PDF 导出界面；使用前需要完成持久化与桌面端入口集成。
