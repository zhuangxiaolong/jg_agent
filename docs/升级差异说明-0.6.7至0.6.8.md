# 精工智能开发平台 0.6.7 升级至 0.6.8 差异说明

适用对象：战区 MES5、MES6、WMS 开发人员  
适用版本：Windows x64 桌面版  
发行日期：2026-11-07

## 结论

0.6.8 的主要用户可见变化是：没有企业 Authenticode 代码签名证书时，正式安装包也可以通过 HTTPS 在线检查和下载更新，并使用 `latest.yml` 中的 SHA512 校验下载文件。由于 0.6.7 及更早版本仍受原签名门禁限制，首次升级到 0.6.8 必须手动安装一次；此后可使用应用内自动或手动更新。

## 升级差异

### 1. 无企业证书时可在线更新

- 0.6.7 及更早版本的在线更新要求发布包配置 Windows Authenticode 发布者签名；未配置签名的安装包不能使用应用内更新。
- 0.6.8 在安装包包含有效更新配置时启用更新。没有企业证书的发布包通过 GitHub HTTPS 获取更新，并校验 `latest.yml` 提供的 SHA512；配置了 Authenticode 发布者签名时仍按签名发布流程处理。
- 下载完成后，在【设置 > 更新】点击【重启并更新】，应用会收尾当前运行并安装更新。应用数据按原有升级流程保留。

### 2. 0.6.7 到 0.6.8 需要手动过渡一次

0.6.7 和更早版本无法通过原有应用内更新机制直接升级到 0.6.8。请从可信的 0.6.8 发布来源下载 `JinggongAgent-Setup-0.6.8-x64.exe`，先从系统托盘菜单彻底退出旧版，再运行安装程序完成覆盖升级。无需先卸载旧版本。升级完成后，可在【设置 > 更新】选择自动更新，或使用【检查更新】与【下载更新】。

### 3. 产品名称统一

桌面窗口、系统托盘、安装程序及相关提示统一使用“精工智能开发平台”名称。应用的本地会话、项目和设置仍由同一 Windows 用户的数据目录管理。

### 4. Windows 无证书发布流程修复

0.6.8 的发布流程可在未配置企业证书时生成并上传 Windows x64 安装包、差分下载文件（`.blockmap`）和更新清单（`latest.yml`）；配置证书时仍可走 Authenticode 签名流程。此项主要改善正式发行与后续在线更新，不增加新的业务开发功能。

## 安全与适用边界

HTTPS 保护更新传输，SHA512 用于核对下载文件与更新清单中的摘要是否一致；它不等同于 Authenticode，也不提供 Windows 可信发布者身份。无证书安装包可能显示未验证发布者。请使用项目正式发布渠道提供的安装程序和更新地址。

0.6.8 继续包含 0.6.7 已提供的首次开发规范同步、MES5/MES6/WMS 内置基础数据字典、会话附件、代码变更与 Git 等功能；这些是延续功能，不属于本次版本增量。实际项目结构、客户扩展字段和业务口径仍以目标项目资料及人工确认结果为准。

## 更新操作

1. 从 0.6.7 或更早版本升级时，手动运行一次 0.6.8 安装程序。
2. 打开【设置 > 更新】，确认当前版本为 0.6.8，并核对更新地址。
3. 选择【自动更新】以在启动时检查并后台下载；或选择【手动更新】，点击【检查更新】，发现新版本后点击【下载更新】。
4. 状态显示更新已下载后，点击【重启并更新】完成安装。

更多界面操作、项目会话、Jira、Git、资料和备份说明见[精工智能开发平台 0.6.8 开发人员使用说明](使用说明-0.6.8.md)。
