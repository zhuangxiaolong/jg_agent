## 可验证行为

1. 外观：精工、极简；深色、浅色、跟随系统，SQLite 持久化。
2. 记忆：真实新增、查看、删除；每轮加载现存记忆。
3. Jira：域名、账号、密码保存，密码 DPAPI 加密且不回显；更换域名/账号必须重新输入密码。
4. 字典：MES5/MES6/WMS/通用文件导入、正文预览、启停与删除；DOCX/XLSX 真实解析，有来源 SHA256。
5. 要求：正文全量注入，JSON 机器规则拦截写入/提交，文字要求提交前需逐份核对。
6. 模型：多个中转站和模型列表，独立密钥、会话选择；不使用原 Codex 登录。
7. 开发：隔离 Worktree 内受控真实文件增改删，hash 并发检查；只读模式仍禁止修改。
8. Git：最近 50 条历史，按真实 Diff 生成中文说明，审核、确认后提交与推送同名 agent 分支。
9. 品牌：使用用户提供的精工图片，窗口和安装包使用对应图标。
