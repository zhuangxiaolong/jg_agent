## 本轮实现范围

### Jira 配置与只读访问

- Jira 地址支持用户指定的 HTTP 或 HTTPS，可粘贴项目页面地址，保存时归一为 Jira Base URL，并从可识别项目页面提取项目 Key；保留合法部署上下文路径。
- 旧调用未显式传入项目范围时，默认项目为 `NEWDEVGROUP`，默认日期字段 ID 为 `11116`；两者可配置。V0.3.2 界面显式传入全部可访问项目或用户选择的具体项目，保留旧调用兼容行为。项目页地址、凭据和模型中转站配置分别处理，不改变模型服务的 HTTPS 约束。
- Jira 密码或 Token 由主进程通过 Windows DPAPI 保护，SQLite 只保存地址、账号、是否已配置及项目/日期字段元数据。更换地址或账号时需要重新输入凭据，渲染界面不回显明文。
- 连接器只提供 REST v2 的 GET 查询，不修改任务状态、负责人、评论或工作日志；请求有超时、响应容量及错误分类，重定向不携带授权继续访问。
- 连接测试读取当前账号及字段元数据，确认账户时区和 Date/Date Time 字段类型。Date 使用指定日期相等查询，Date Time 使用当天零点至次日零点的半开区间；日期按 Jira 返回的账户时区解释。管理员独立配置实例时区的完整能力不在本轮验收结果中预先承诺。

### 任务面板与会话快照

- 任务面板提供最近任务/日报任务范围、日期、分页与可选本人任务筛选。V0.3.2 增加全部可访问项目或具体项目选择，项目范围默认全部可访问项目；字段包含 Key、概要、状态、类型、负责人、优先级、更新时间、描述及原始链接。新增行为的实际验收状态见上节。
- 用户选择任务和已登记本地仓库后创建关联会话；主进程重新读取任务详情，保存 Issue Key、概要、正文、来源 URL、附件元数据和获取时间，避免只信任渲染进程传入的任务正文。
- 会话快照明确挑选字段，描述最多 100,000 字符，附件最多 200 条元数据；超限或识别到真实凭据时拒绝保存，不静默截断。额外密码、认证头及附件二进制不入库。
- 任务来源必须为有效 HTTP/HTTPS 地址。安全检查无法开放的附件链接以空 URL 保留清单元数据，不因此丢弃整个任务；非空授权链接仍拒绝保存。
- SQLite JSON 字段向后兼容，无需提升 schema 版本；旧 Jira 配置由服务/连接器补默认值，数据库读取本身不改写旧配置。
- Jira 描述和附件清单作为不可信业务资料进入会话，不能覆盖开发要求、读取凭据或增加工具权限。

### 开发要求与规范

- 设置中提供独立“开发要求与规范”入口，支持上传文件及直接输入、编辑标题与正文；可以按 MES5/MES6/WMS/通用分类查看、启停和删除。0.3.1 将新增要求的默认适用范围调整为“通用”，已用现用数据目录实际确认默认“通用”，上传按钮与正文输入均可见，未更改既有规范。
- 输入保存沿用同一资料 ID，更新内容摘要；未写扩展名时保存为 `.md`，`.json` 必须符合机器规则格式。单份开发要求仍最多 80,000 字符，完整要求进入上下文；整体超限明确拒绝，不裁剪。
- JSON 支持 `forbid-text`、`require-text`、`require-file`；受控写入前检查，Git 提交前再检查实际暂存 blob，并以固定 tree 提交。
- 修复规则自身 `./` 路径与被检文件归一方式不一致的问题：例如 `./src/./*.ts` 按 `src/*.ts` 匹配。写入与提交阶段均不能借此绕过禁止文本或必需文件删除检查；绝对路径、反斜杠、`..`、空段和大小写形式的 `.git` 仍拒绝。
- 自然语言规范完整提供给 Agent，提交前由用户逐份核对；不能把人工复核项表述为已被机器证明符合。
- 主界面已完成精工品牌化，面向用户使用精工 Agent/引擎名称；内置运行时版本和技术归属仍如实保留在工程记录中。0.3.1 安装后的实际界面回归通过；用户业务正文、代码和真实路径保持原样。
