## 本轮行为

- 从本地项目或 Jira 任务新建会话，默认采用“隔离开发”。每会话仍可选择只读分析；旧会话保持原有模式，不把历史只读会话自动改为开发。独立 `agent/*` Worktree、写入规则及用户确认提交/推送的边界保持不变。
- Jira 固定在右侧工作区，与中央 Agent 会话同时使用。查看 Jira、选择关联本地项目和切换右侧标签不卸载中央会话，也不丢失未发送的任务草稿。
- Jira 完整配置后读取账户时区，默认按该时区当天、全部可访问项目、日报日期和仅本人自动抓取第一页。每次启动及跨 Jira 日期时自动尝试一次；失败显示明确错误并保留成功读取的本地记录，不伪装成成功空列表。
- 手动日期、项目、负责人筛选及历史记录仍可使用；手动选择后暂停自动模式，“恢复今日自动抓取”回到当天默认条件并主动刷新。隐藏 Jira 或切换标签不重复抓取；未配置时明确提示且不发 Jira 请求。
- 项目与会话侧栏、右侧任务与代码面板、底部运行输出和工具活动均可隐藏、恢复。恢复入口始终留在顶部。三个显示状态保存至 SQLite `settings.layout`，重启恢复；默认均显示，不升级数据库 schema。

## 验收标准与证据

自动脚本 [v05-smoke.mjs](../../scripts/v05-smoke.mjs) 使用隔离临时数据目录、真实 Electron、IPC、DPAPI、SQLite 和本地 Git 仓库；Jira 服务是明确合成的 loopback HTTP，不访问用户真实 Jira 或模型。

1. 从 UI 新建普通会话和 Jira 关联会话均保存 `mode=develop`；已有 `read` 会话重启后保持只读，源 main 的 HEAD 和文件不变。
2. 未配置 Jira 时中央工作区与右侧提示同时可见，HTTP 请求为零。配置合成 Jira 后无需点击抓取，按 `Pacific/Honolulu` 账户当天查询，核对 UI 日期、JQL、分页结果时区与 SQLite 记录。
3. 主会话与右侧 Jira 并存，三面板逐一隐藏/恢复和标签切换不重复 search，中央草稿保留。全隐藏后重启仍从本地恢复，并可通过顶部逐一展开。
4. 自动网络失败保留原查询 ID、结果和读取时间并显示错误；手动历史选择、刷新、恢复自动均与显示条件一致，刷新失败不清空旧任务。
5. 真实 SQLite 不含合成模型密钥或 Jira 密码明文；Renderer 不直接请求远程；Jira 夹具只收到 GET，无模型请求。

运行命令：

```powershell
npm run build
node scripts/v05-smoke.mjs
```
