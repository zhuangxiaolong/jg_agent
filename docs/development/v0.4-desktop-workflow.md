## 本轮变更

- 本地项目可以修改显示名称，名称保存在 SQLite；仓库路径、项目 ID、源分支与既有工作区不随显示名称修改。名称为空、超长、控制字符或已知凭据时拒绝保存。
- 会话增加独立别名，显示时优先使用别名；留空保存表示清除别名并恢复默认标题。别名不改写默认 title、任务来源、会话 ID 或 Worktree，后续调整会话模型/模式时仍保留别名。
- 每会话增加模型推理强度：模型默认，以及 `none`、`minimal`、`low`、`medium`、`high`、`xhigh` 六档。模型默认不发送强制 effort；实际支持档位和效果由所选模型与中转站决定，界面提供选项不等于所有 provider 均支持。
- 外观新增紫色、黑色、天空蓝、草绿色主题，保留深色、浅色、跟随系统及两种界面风格；偏好仍由本地数据库保存。
- Jira 成功查询按连接与账号范围保存查询条件、分页结果和读取时间，支持打开本地历史，区别本地快照与主动重新抓取；认证、网络或字段失败不能伪装成成功空结果。记录需要明确来源与更新时间。
- Jira 图片附件支持受控下载、预览与本地内容哈希缓存；创建关联会话时完整准备受支持图片，通过 Runtime 的原生图片输入传给模型，不能用图片文件名或文字占位冒充图片内容。非图片附件的通用下载解析仍属后续范围。
- Git 页增加“拉取当前分支”。操作由用户确认，仅更新应用管理的独立 `agent/<session>` Worktree；远程固定当前分支同名 ref，不拉取源 main，也不按仓库自定义 refspec 更新其他分支。
- 关闭窗口隐藏到系统托盘；托盘支持恢复窗口和明确退出。真正退出由应用统一结束 Runtime 并关闭数据库，执行中的 Git 操作或会话创建应先完成，运行中任务退出需要确认中断。
- 修复单实例锁失败后仍进入 whenReady 初始化的问题：二次启动曾继续创建窗口并可能弹出启动失败。当前仅主实例初始化 Runtime/数据库/窗口，非主实例直接退出；二次启动应恢复原窗口，不新增会话或重复初始化。

## Git 拉取的实现与安全边界

`GitConnector.pull(workspacePath, remote)` 先校验工作区身份、当前分支、远程名称与单一地址，复用推送的传输安全边界。支持已配置 SSH Agent 的 SSH 地址及本地真实 Bare 仓库；HTTPS 不调用仓库自定义 credential helper，需认证的 HTTPS 拉取仍有明确限制与中文提示。

拉取显式读取当前 agent 同名分支，fetch 到独立临时 ref，不写 FETCH_HEAD、不跟随标签、不递归子模块，不应用自定义 fetch refspec。先检查祖先关系，再以 `merge --ff-only --no-autostash` 快进更新工作树、索引和 HEAD；不产生合并提交，不 rebase/reset/force，不自动解决分叉或覆盖冲突。本地已领先时保持本地提交。

脏工作区、无远程同名分支、分叉、URL 重写、多地址、带凭据或不受支持的传输协议均明确拒绝。禁用 Hook、Filter、外部 Diff/Textconv 与自动维护；拉取涉及目录联接、符号链接或硬链接时拒绝，不能覆盖本地被忽略文件。错误不转发远程 stderr 中可能存在的地址和凭据。

## Jira 图片与记录边界

- 图片仅从已配置 Jira 的同源及相同部署 context 路径读取，使用只读 GET；拒绝包含用户名密码的 URL、跨站和重定向，不将授权发送到外站。
- 支持 PNG/JPEG/GIF/WebP；声明 MIME 仍须属于支持的图片类型，实际文件签名决定缓存 MIME 与后缀，兼容历史附件 JPEG 被错标为 PNG。检查真实容器边界及尺寸，拒绝 SVG/HTML/登录页。单张不超过 8 MiB、4000 万像素，每任务最多 20 张、累计 32 MiB；失败或超限明确拒绝，不能悄悄丢图创建会话。
- V0.4.1 按 JPEG marker 结构解析到扫描数据及 EOI，允许有界尾元数据并仅把截至 EOI 的规范化图片写入缓存/预览/模型输入；源 Jira 附件不变。真实样本的 EOI 后含 24 字节尾内容，不能仅以响应最后两个字节是否为 EOI 判断合法 JPEG。
- 缓存文件路径由可信本地数据根及 SHA256 生成，不接受渲染进程指定路径。写入使用独占临时文件、同步和原子重命名；读取检查目录身份、链接、大小、SHA256 与图片类型，缓存损坏、缺失或目录被替换时明确失败。
- SQLite 只保存图片 SHA256、类型和大小等元数据，不保存 Jira 密码或授权头；本地已完整缓存图片可以离线预览，会话使用完整缓存图片时也不要求重新读取 Jira 凭据，缺图时才创建连接下载。图片文件与用户原附件来源分别保留，不改写源附件。
- 查询缓存按 Jira 地址、账号及日期字段隔离，单范围最多保留 50 条分页查询，全部范围的详情合计最多 200 条，查询/详情 JSON 全局总预算 64 MiB；超出预算淘汰旧缓存，不静默裁剪任务正文。跨账号或连接切换时在途请求不得写入新连接范围。
- 查询与详情缓存复用 SQLite 的 settings JSON 项，无需升级 schema；图片按内容哈希保存为独立文件。主进程在网络请求前固定连接范围与 connector，返回/保存前重新确认范围；创建会话期间拒绝修改配置，防止旧响应写入新账号记录。
