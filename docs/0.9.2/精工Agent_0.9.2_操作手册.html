安装后已有的手册

首次启动时，应用会校验安装包中的手册文件并复制到当前 Windows 用户数据目录，随后后台建立可检索索引。内置手册会显示“安装包内置手册”。

iMES5.9 操作手册 V1.1分类 MES5，产品版本 iMES 5.9
SRM 系统操作手册分类 SRM
JMOM 仓库和品质模块操作手册分类 JMOM
PDA 移动仓库和品质操作手册分类 PDA
MES6 分类已保留。现在没有 MES6 手册也可以正常使用，之后选择 MES6 分类导入即可。

打开产品手册

  1. 启动精工 Agent 并等待主窗口加载。
  2. 点击左下方“全局设置”。
  3. 在设置导航中打开“产品手册”。
  4. 在“手册库”查看分类、状态、版本和解析信息。

新安装或首次运行时，内置手册可能先显示“等待处理”或“处理中”。解析在后台完成，页面会自动刷新状态。

导入手册

  1. 在“导入手册”填写默认产品分类、产品版本、手册版本、生效日期和适用范围。
  2. 点击“选择手册文件”，从文件对话框中选择一份或多份资料。
  3. 在待导入列表中逐本确认产品分类和版本。选择 MES6 手册时，将分类设为 MES6。
  4. 点击“导入并解析”，文件会复制到本机知识库并进入后台队列。

支持 PDF、DOCX、XLSX、PPTX、Markdown、TXT 和 HTML。单文件最大 100 MiB，每批最多 20 个文件。批量导入可以分别设置分类，也可以把默认信息应用到全部文件。

相同产品分类下重复导入同一文件时会提示已有记录，不会新建重复索引。

重新上传并替换

替换适用于内置手册更新版或用户手册的新版本。替换保留手册记录和分类，解析成功后更新活动文件与索引。

  1. 在“手册库”选择需要更新的手册。
  2. 点击“重新上传并替换”，并且只选择一个文件。
  3. 等待后台解析结束。完成后，文件名、摘要和搜索结果会切换到新版本。
解析成功后旧原件会清理，新的 DOCX 和索引一起生效。解析失败、取消或应用中断时，原手册及原索引会保留，可以修复文件后再次替换。

内置手册支持停用和替换，不能直接删除。普通用户导入的手册可以在详情中删除。

选择会话知识范围

在“手册范围”选择会话，再设置产品知识范围。

  • 自动匹配按当前会话识别出的产品范围检索。问题明确提到 MES5、MES6、WMS、SRM、JMOM 或 PDA 时，按问题临时选择对应产品。
  • MES5、MES6、WMS、SRM、JMOM、PDA检索所选产品和通用手册。
  • 关闭手册检索停用当前会话的手册上下文。
未知项目且问题没有明确产品范围时，不会自动混合不同产品的手册。可以在此手动指定范围。

查看内容和测试检索

  • 手册详情展示 SHA-256、文件大小、提取字符数、片段数量及页数、工作表数或幻灯片数。
  • “测试检索”可选产品范围并输入操作问题，检查召回片段、匹配分数和来源定位。
  • 解析片段预览展示章节、页码、工作表或幻灯片位置。
  • 对话检索到手册时，模型上下文会携带固定来源标识，提示模型引用并标注资料未说明的部分。

用户可修改名称和适用元数据、停用或启用手册、重新解析、取消排队任务或删除自己导入的资料。

解析状态与内容范围

  • 可用文本解析和索引已完成，可以参与检索。
  • 部分可用存在未被当前解析器处理的内容，例如 DOCX 内嵌图片。
  • 解析失败没有可检索内容或文件格式、内容无法解析。可更换文件后重试。
当前版本没有 OCR。DOCX 图片会显示图片数量和部分解析提示，图片中的文字不会建立索引。SRM 手册可提取的正文较少且含有截图，手册状态可能是“部分可用”，检索不到截图文字。

扫描版 PDF 没有可搜索文字时不会建立成功索引。DOCX 章节按文档标题和抽取段落定位，不能保证对应原始页码。

本地存储和模型请求

索引存入本地 SQLite 数据库。Windows 默认原件目录为 %LOCALAPPDATA%\JinggongAgent\knowledge\manuals\originals。用户替换后的文件仍保留在本机数据目录，不会随更新安装包恢复为初始版本。

手册全文不会在每轮发送。检索命中的片段会作为当前会话上下文发送给已配置的模型服务，用于回答当前问题。
