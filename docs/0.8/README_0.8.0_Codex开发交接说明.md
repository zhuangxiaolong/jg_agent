# 精工 Agent 0.8.0 — Codex 开发交接说明

本目录包含 0.8.0 性能优化迭代的两份核心文档：

1. `精工Agent_0.8.0_性能优化需求规格说明书.md`：明确做什么、优先级、用户场景、验收标准和版本边界。
2. `精工Agent_0.8.0_性能优化技术设计方案.md`：明确如何实施、架构边界、关键模块、测试和阶段安排。

## 给 Codex 的首轮任务

请先读取以上两份文档和当前仓库代码。第一轮**只做代码现状核对和实施计划，不要立即大范围修改**。

请重点检查：

- Runtime 创建、复用、关闭与恢复的完整生命周期；
- `sessionId -> Runtime instance -> App Server process -> Thread ID` 的映射和隔离；
- RuntimeReuseKey 是否覆盖所有影响 Runtime 行为的配置；
- 当前预热到底做了什么，是否可以安全地预启动 App Server；
- MES5/MES6/WMS 字典、开发规范、JIRA 信息和历史消息如何进入上下文；
- 平台工具注册和执行方式，哪些工具确实只读、幂等；
- Renderer 如何接收流式事件、更新消息 Store 和渲染消息；
- 现有测试、构建命令和 Windows 打包流程。

第一轮请输出：

1. 当前代码架构与本需求的映射表；
2. 已经具备的能力，避免重复开发；
3. 需要新增或调整的能力；
4. 影响文件清单；
5. 风险和兼容性问题；
6. 按阶段拆分的实施计划及每阶段验收方法；
7. 当前可运行的测试命令及测试结果。

完成核对后，再按技术设计方案的阶段 1～5 实施。不得自行升级 Codex Runtime 依赖、改变 API 协议、默认开启 Multi-Agent 或扩大 Runtime 权限。任何性能结论必须来自可重复测试数据。
