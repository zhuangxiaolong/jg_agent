# 精工 Agent 0.6.1 使用说明

## 1. 启动与首次配置

运行安装包完成安装后打开“精工 Agent”。首次使用进入“全局设置”：

1. 在“模型中转站”配置 HTTPS 地址、模型名称和密钥，点击保存。
2. 在“外观”确认深色主题、字体和完成提示音；可试听提示音，也可选择关闭。
3. 在“开发要求与规范”上传或录入项目开发规范。开发会话开始前会自动注入并执行规则检查。
4. 在“数据字典”导入项目允许使用的资料。新会话会根据仓库指纹自动识别 MES5、MES6 或 WMS，并只加载对应字典。

## 2. 创建项目和会话

左侧项目栏按项目分组显示会话。使用“新建项目”选择一个有提交记录的 Git 仓库，再点击项目下的“新建会话”。应用会建立隔离 Worktree；项目和会话名称均可修改。

删除项目必须先删除其全部会话。删除会话前会检查隔离 Worktree，存在未提交改动时会拒绝删除，避免误删开发内容。

每个会话可以单独设置模型中转站、模型、MES 系统、开发/只读模式和推理强度；这些设置位于会话标题下方，主界面不再单独设置中转站。

## 3. Jira 任务与图片

在右侧 Jira 面板查询任务，打开详情后点击“创建会话”。任务正文、附件元数据和可用图片会保存到会话快照。图片会在发送首轮任务时作为原生图片上下文传给模型，图片无法安全下载时会保留明确的不可用提示。

创建会话后，首轮任务会先进行“开发条件审查”：检查需求描述、验收标准、仓库代码、数据字典和开发规范。如果信息不足，Agent 会列出缺失问题并提示“需求不完整，暂不修改”；只有条件可以确认时才进入分析、方案和编码。

## 4. 会话操作

消息区停留在底部时会跟随新输出；向上查看历史消息时不会被新消息顶回顶部。需要回到底部时点击“回到最新消息”。输出支持 Markdown 标题、目录、重点、引用、表格、代码块和路径高亮。

Agent 整轮任务不设置 30 分钟硬时限，任务会持续到协议终态或用户点击停止。完成、失败和取消都会写入本地会话事件，并按“外观”中的提示音设置提醒。

## 5. 在线更新

进入“全局设置 > 更新”：

- “自动更新”：启动后静默检查并后台下载，下载完成后点击“重启并更新”。
- “手动更新”：点击“检查更新”，发现版本后点击“下载更新”，完成后重启更新。

更新文件会覆盖当前安装目录，旧数据、项目、会话和凭据保留。在线更新要求发布包配置签名和 GitHub 更新源；本地未签名测试包会明确显示“未配置更新签名”，不能执行在线更新。

## 6. 建议开发流程

1. 导入开发要求与数据字典。
2. 选择或创建项目，确认自动识别的 MES5/MES6/WMS 系统。
3. 从 Jira 创建会话，先查看开发条件审查结果。
4. 在会话中确认方案和范围，再允许 Agent 修改代码。
5. 在“代码变更”检查 Diff，运行项目构建和测试。
6. 通过人工复核后再提交和推送 `agent/*` 分支。

## 7. 本地数据与故障处理

项目、会话、事件和配置保存在本机应用数据目录；模型密钥使用 Windows DPAPI 保存，不会写入会话正文。遇到运行问题，先查看会话中的错误事件和“代码变更”状态，确认 Worktree 没有未提交修改后再删除会话或重新创建。
