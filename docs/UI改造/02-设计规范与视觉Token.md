# 精工 Agent UI 设计规范与视觉 Token

建议作为现有主题变量的基准。若项目已有设计 Token，优先映射到现有变量，不要重复创建两套体系。

## 1. 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `--app-bg` | `#0B1220` | 应用最底层背景 |
| `--sidebar-bg` | `#0F1726` | 左侧导航 |
| `--surface-1` | `#131E2E` | 主卡片/工作区 |
| `--surface-2` | `#182437` | 次级卡片/输入区 |
| `--surface-3` | `#202E43` | Hover/浮层 |
| `--border` | `#2A3A50` | 常规边框和分隔线 |
| `--border-strong` | `#3A4D66` | 强调边框 |
| `--text-primary` | `#E8EEF6` | 主文本 |
| `--text-secondary` | `#A5B3C5` | 次级文本 |
| `--text-muted` | `#78889D` | 辅助说明 |
| `--accent` | `#3B82F6` | 主要按钮、链接、选中态 |
| `--accent-hover` | `#60A5FA` | 主要交互 Hover |
| `--success` | `#22C55E` | 成功/正常 |
| `--warning` | `#F59E0B` | 警告/待处理 |
| `--danger` | `#EF4444` | 失败/危险 |
| `--info` | `#38BDF8` | 信息状态 |

规则：
- 不要把所有卡片都做成不同蓝色。
- 不要用大面积高亮蓝色作为背景。
- 状态颜色只用于状态，不作为普通装饰色。
- 重要文字在实际背景上必须可读；必要时提高文本明度。

## 2. 字体

```css
font-family: "Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", "Segoe UI", Arial, sans-serif;
```

代码字体：

```css
font-family: "JetBrains Mono", "Cascadia Code", Consolas, monospace;
```

不建议强制下载字体。优先使用系统字体和项目已安装字体。

## 3. 字号与字重

| 场景 | 字号 | 字重 | 行高 |
|---|---:|---:|---:|
| 页面/任务主标题 | 18–20 px | 600 | 1.35 |
| 区域标题 | 15–16 px | 600 | 1.4 |
| 正文/聊天消息 | 14–15 px | 400 | 1.6 |
| 导航项/按钮 | 13–14 px | 500 | 1.4 |
| 表格/列表内容 | 13 px | 400 | 1.45 |
| 辅助说明/时间 | 12 px | 400 | 1.4 |
| 代码/终端 | 12.5–13 px | 400 | 1.55 |

避免将关键功能说明压到 11 px 或更小。小字只用于次要时间戳或非关键元数据。

## 4. 间距

使用 4 px 基础单位：

- 4 px：图标与文字微间距。
- 8 px：紧凑控件内部间距。
- 12 px：列表项和标签间距。
- 16 px：常规卡片内边距。
- 20 px：区块内边距。
- 24 px：主要区块间距。
- 32 px：页面级分组间距。

同一层级使用一致间距，不要在同一张卡片中出现大量任意数值。

## 5. 圆角、边框与阴影

| 元素 | 圆角建议 |
|---|---:|
| 小按钮/输入框 | 6–8 px |
| 卡片/面板 | 10–12 px |
| 弹窗/抽屉 | 12–16 px |
| 状态徽标 | 6 px 或胶囊形，选定一种主规范 |

- 边框默认 1 px。
- 阴影轻量，主要用于弹窗、下拉菜单和浮层。
- 主工作区不需要每个容器都有明显阴影。
- 禁止大面积霓虹发光效果。

## 6. 图标规范

- 优先统一使用当前项目已有图标库；若为 Lucide，使用 Lucide outline。
- 尺寸：16 / 18 / 20 / 24 px 四档。
- 默认描边：1.75–2 px。
- 导航图标 18–20 px；行内图标 16 px；空状态图标 24 px。
- 功能图标禁止混入 Emoji。
- IconButton 必须有 Tooltip 和可访问名称。

## 7. 控件尺寸

| 控件 | 高度建议 |
|---|---:|
| 小按钮 | 28–32 px |
| 常规按钮 | 34–38 px |
| 主要按钮 | 36–40 px |
| 输入框 | 36–40 px |
| 导航项 | 36–40 px |
| Tab | 36–40 px |
| 状态徽标 | 22–26 px |

同一工具栏内按钮高度、图标对齐方式和左右内边距必须一致。

## 8. 状态表达

状态统一采用「图标 + 文字」，不能单靠颜色：

- 运行中：蓝色/信息色 + 运行图标。
- 已完成：绿色 + 勾选图标。
- 等待中：中性灰 + 时钟/圆点图标。
- 警告：黄色 + 警告图标。
- 失败：红色 + 错误图标。
- 未连接：中性灰 + 断开连接图标。

避免不必要的动画；运行状态可以使用轻量旋转或呼吸提示，但需尊重系统减少动态效果设置。

## 9. 交互状态

每种可交互控件都必须覆盖：
- Default
- Hover
- Focus-visible
- Active
- Disabled
- Loading（适用时）

键盘焦点需要明显可见。不可仅通过颜色变化表达焦点。
